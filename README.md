# runakemb
Stitch Studio Pro · v5.0Stitch Studio Pro is a modern, responsive, web-based embroidery design editor and viewer. Built completely in client-side HTML, CSS, and vanilla JavaScript, it allows users to view, edit, convert, and generate embroidery pattern files entirely within the browser without uploading data to external servers.🌟 Key FeaturesMulti-Format Support: Read and write major industry embroidery formats:DST (Tajima)PES (Brother)EXP (Melco)JEF (Janome)Digitizing Tools (Create from scratch):Text → Stitches: Convert any text using system fonts into embroidery stitch patterns with customizable size (mm) and letter spacing.Image → Stitches: Convert raster images (PNG, JPG, etc.) into stitch patterns with adjustable detail/resolution and automatically mapped thread colors.Editing Capabilities:Interactive canvas pan and zoom.Single piece selection and bounding-box rectangle selection (Rect Select).Stitch deletion for selected areas or specific thread colors.Scale (width/height in mm or percentage), flip (horizontal/vertical), and 90° rotation.Custom origin/start point relocation (Center, Top-Left, Bottom-Right, First Stitch, Picked, etc.).Color reduction algorithm to limit maximum thread palette size (2 to 12 colors).Visualization & Preview:Animated stitch progress preview slider (0% to 100%).Toggle jump stitch lines on/off.Custom fabric background color preview.Direct export to PNG preview image.Multilingual UI: Built-in internationalization support:EnglishArabic (العربية) (RTL Layout)Kurdish (کوردی) (RTL Layout)Mobile-Optimized Experience: Fully responsive layout with custom mobile navigation bar, bottom action sheets, and touch event handling.🚀 Getting StartedSince Stitch Studio Pro is a self-contained single-page application (SPA), running it requires no build steps, package managers, or server setups.Quick StartDownload or clone the repository containing index.html.Open index.html directly in any modern web browser (Chrome, Edge, Firefox, Safari).🛠️ Usage InstructionsOpening a DesignClick Open (or press Ctrl+O) from the toolbar or sidebar.Select a .dst, .pes, .exp, or .jef file from your device.Creating StitchesFrom Text:Open the Create section.Select Text → Stitches.Enter your text, choose a font family, set dimensions in millimeters, and pick a thread color.Click Generate Text.From an Image:Open the Create section and switch the source to Image → Stitches.Upload an image file, adjust target dimensions (mm) and detail level.Click Generate Image.Editing & SelectionSelect Tool (V): Click individual stitch segments to select them.Rect Select Tool (R): Click and drag a box on the canvas to select a region of stitches.Delete: Use the Delete button in the selection panel or remove specific thread colors using the ✕ icon in the Thread Colors panel.Start Point (S): Pick a preset start position or click directly on the canvas to set a custom origin.Exporting FilesOpen the Save / Export panel.Select your desired export format (DST, EXP, JEF, or PES).Set your target file name and click Save Stitch File.You can also export a visual preview by clicking Save Preview PNG.⌨️ Keyboard ShortcutsShortcutActionCtrl + OOpen embroidery fileCtrl + SSave embroidery fileCtrl + ZUndo last actionCtrl + YRedo
